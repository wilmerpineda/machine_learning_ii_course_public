Semana 02 — Quiz práctico de precios de vivienda

Propósito

Aplicar fundamentos de ML1 y árboles de decisión en una evaluación individual

tipo competencia de datos: construir una referencia, calcular Gini, seleccionar

la complejidad de un árbol de regresión y generar predicciones para viviendas

con precio oculto.

Quiz práctico — 1,0 %

  • Caso de predicción de precios de vivienda inspirado en Ames Housing.
  • Código Python, resultados numéricos y tres explicaciones breves.
  • Identificación mediante documento y correo institucional.
  • Una entrega definitiva; el código puede ejecutarse libremente antes de enviar.
  • Sin apuntes, internet, IA ni colaboración.
  • 8,5 puntos automáticos y 1,5 puntos de revisión docente.
  • La retroalimentación se libera después de las 8:55 a. m.

Evidencias solicitadas

1. MAE de un baseline que predice la mediana.

2. Gini, impureza ponderada, reducción de impureza y probabilidad de hoja.

3. Comparación de cuatro configuraciones mediante entrenamiento y validación.

4. Selección sin consultar el precio de las viviendas de test.

5. Archivo submission con Id y SalePrice.

6. Justificación del protocolo y una limitación del modelo.

Restricciones

  • No cambiar la partición de desarrollo y validación.
  • Usar solamente DecisionTreeRegressor.
  • Comparar exactamente las cuatro configuraciones incluidas.
  • No usar ccp_alpha, Random Forest, boosting ni otros ensambles.
  • No utilizar Id ni SalePrice como predictores.
  • No se califica obtener el menor MAE del salón; se califica la calidad del procedimiento.
