Colab no es producción

El runtime es temporal, puede terminar y no ofrece una identidad operativa estable.

La salida valiosa no es la sesión: son los artefactos descargados.

Pedir ejemplos de lo que desaparece cuando termina el runtime.

Docker congela la receta

Capas

base → dependencias → código → artefactos

Contrato de ejecución

usuario no root → puerto → salud → comando

Compose describe el sistema

Internet → Caddy :443 → app :8501

Caddy guarda certificados en volúmenes.

Streamlit solo existe en la red interna.

Contrastar expose con ports. El puerto 8501 nunca se publica.

[Sources] Docker Compose quickstart; Caddy, Automatic HTTPS. [/Sources]

Compose se construye por etapas

  1. app y construcción
  2. prueba de salud
  3. Caddy y dependencia saludable
  4. volúmenes persistentes

En cada etapa: predecir → completar → validar → ejecutar → inspeccionar → explicar.

El comando de seguridad es docker compose config antes de levantar.

[Sources] Docker Compose quickstart. [/Sources]

Solo tres puertas

Flujo Origen Destino
HTTP Internet TCP 80
HTTPS Internet TCP 443
SSH IAP 35.235.240.0/20 TCP 22

No: 8501 público.

Las reglas usan el tag streamlit-web para no afectar otras VMs.

[Sources] Google Cloud, IAP TCP forwarding; VPC firewall rules. [/Sources]

HTTPS tiene dependencias observables

  • El dominio debe resolver a la IP.
  • Los puertos 80/443 deben llegar a Caddy.
  • Caddy debe poder obtener y conservar el certificado.

Nombre de aula: IP-con-guiones.sslip.io

Si sslip.io está bloqueado, probar nip.io. Revisar logs antes de cambiar cosas.

[Sources] Caddy, Automatic HTTPS; sslip.io documentation. [/Sources]

“Running” no significa “healthy”

Inspeccionamos:

  • estado de Compose;
  • endpoint de salud;
  • logs de app y Caddy;
  • redirección HTTP → HTTPS;
  • predicción de referencia;
  • ausencia de 8501 público.

Un proceso puede vivir y no responder correctamente.

[Sources] Docker Compose quickstart, health checks and logs. [/Sources]

La explicación no es causalidad

SHAP responde:

¿Cómo contribuyeron estas variables a la salida de este modelo?

No responde:

¿Qué intervención causará que una persona no abandone?

La interfaz incluye esta advertencia de uso responsable.

[Sources] Lundberg & Lee (2017), NeurIPS; documentación SHAP. [/Sources]

El despliegue termina al limpiar

Eliminar VM y disco · comprobar IP · retirar reglas · revisar facturación.

Una infraestructura que nadie puede retirar tampoco es reproducible.

Recolectar evidencia antes de eliminar. Eliminar solo dentro del proyecto exclusivo del equipo.

[Sources] Google Cloud, Delete a VM; Google Cloud, Budgets and alerts. [/Sources]
